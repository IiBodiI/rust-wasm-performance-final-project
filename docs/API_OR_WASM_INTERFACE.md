# API or WASM Interface

This project is client-side only and does not expose REST endpoints. No `openapi.yaml` is required. The stable integration surface is the generated WebAssembly module from `crates/wasm-core`.

Import pattern:

```ts
import { loadWasm } from "./wasm/wasmLoader";

const wasm = await loadWasm();
const version = wasm.wasm_version();
```

## Exported Functions

### `wasm_grayscale(data, width, height) -> Uint8Array`

- `data`: RGBA pixel buffer
- `width`: image width in pixels
- `height`: image height in pixels
- Returns a new RGBA buffer with luminance grayscale.
- Throws if buffer length is not `width * height * 4`.

### `wasm_blur(data, width, height, radius) -> Uint8Array`

- Applies box blur with a capped radius.
- Returns a new RGBA buffer.

### `wasm_edge_detect(data, width, height) -> Uint8Array`

- Applies Sobel edge detection after grayscale conversion.
- Returns a new RGBA buffer.

### `wasm_mandelbrot(width, height, max_iter, zoom, offset_x, offset_y) -> Uint8Array`

- Renders a Mandelbrot fractal into an RGBA buffer.
- Buffer length is `width * height * 4`.

### `wasm_hash_password(password, salt) -> string`

- Uses PBKDF2/SHA-256 with 120,000 iterations.
- Returns `pbkdf2-sha256$iterations$salt$hash`.
- Educational only, not a full authentication system.

### `wasm_generate_qr(text) -> Uint8Array`

- Returns a QR matrix binary format.
- First 4 bytes: little-endian `u32` matrix size.
- Remaining bytes: `0` or `1` module values.

### `wasm_compress(data) -> Uint8Array`

- Compresses bytes using zlib through `miniz_oxide`.
- Browser demo limit is 10 MB.

### `wasm_decompress(data) -> Uint8Array`

- Decompresses zlib bytes generated by `wasm_compress`.
- Throws if input is invalid zlib data.

### `wasm_numeric_loop(iterations) -> number`

- Runs a deterministic floating-point loop for benchmark comparison.

### `wasm_version() -> string`

- Returns the crate version string.

## Example Image Usage

```ts
const wasm = await loadWasm();
const output = wasm.wasm_edge_detect(inputPixels, width, height);
canvasContext.putImageData(new ImageData(new Uint8ClampedArray(output), width, height), 0, 0);
```

## Error Handling

Rust functions return `Result<T, JsValue>`. In TypeScript this appears as a normal function that throws on error, so UI code should wrap calls in `try/catch` and show a friendly alert.
